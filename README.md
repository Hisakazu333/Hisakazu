# hisakazu.dev — Zijie Huang

Personal homepage of Zijie Huang, used for identity verification
(OpenReview / TMLR). Single minimal page, no JavaScript.

## 技术栈

- [Astro](https://astro.build) — 静态站点生成，输出单个 `index.html`
- 白底 serif 学术风，零 JS

## 开发

```bash
npm install        # 安装依赖
npm run dev        # 本地开发 http://localhost:4321
npm run build      # 构建到 dist/
npm run preview    # 预览构建产物
```
